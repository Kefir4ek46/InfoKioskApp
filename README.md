# 📚 InfoKioskApp  
Приложение полностью разрабатывалось ChatGPT. С меня только идея.
---
Интерактивное школьное информационное приложение, разработанное для отображения расписания, постов, документов, погоды и других данных на школьном инфокиоске.  
Поддерживает удалённый доступ и удобное администрирование.

---

## 🚀 Возможности

### 🕒 1. Статус урока
- отображение текущего урока  
- сколько прошло времени  
- сколько осталось  
- автоматический переход между уроками  
- подсветка активного урока  

### 🗓️ 2. Учебный календарь
- отображение каникул, праздников, выходных  
- единая визуальная схема  
- данные управляются через админ-панель  

### 📄 3. Документы
- поддержка PDF, JPG, PNG  
- автоматическая загрузка документов  
- удобный просмотр внутри приложения  

### 📰 4. Посты и объявления
- категории  
- изображения  
- поддержка удалённой загрузки  

### 🌤 5. Погода
- отображение текущей температуры и состояния погоды  
- обновление в реальном времени  

### 🌐 6. Сайт школы
- быстрый переход на официальный ресурс  (требуется замена в коде)

### 📚 7. Расписания
- **основное расписание** (Excel)  
- **изменённое расписание** (Excel, Docx, изображения)  
- подсветка текущего урока (только Docx)  
- поддержка дополнительных расписаний  

### 🔧 8. Удалённый доступ
- загрузка расписаний  
- загрузка документов  
- управление постами

# 🛠 Технологии и библиотеки

| Компонент | Используемая технология |
|----------|--------------------------|
| UI | WPF (.NET 9) |
| Основной язык | C# |
| Excel | ClosedXML |
| DOCX | OpenXML SDK |
| Работа с JSON | System.Text.Json |
| Удалённый сервер | встроенный HTTP-сервер (Self-Hosted) |
| Документы | встроенные средства + PDF решения |
| Анимации и UI | XAML + Storyboards |
