# Расширения InfoKiosk

Папка для расширений (плагинов), расширяющих функциональность киоска. Каждое
расширение может состоять из трёх механизмов:

1. **Отображение в киоске** — вкладка с UI (`view.js` + опц. `view.css`).
2. **Отображение в админке** — настройки (`settingsFields` в `plugin.json`,
   рендерятся автоматически).
3. **Логика** — бэкенд-обработчик (C#-плагин с `IPlugin` или встроенная команда
   `WebMessageBridge`).

## Манифест `plugin.json`

```json
{
  "id": "canteen",
  "name": "Столовая",
  "icon": "🍽",
  "version": "1.0.0",
  "author": "InfoKiosk",
  "description": "Меню столовой на день.",
  "order": 50,
  "defaultPosition": "after-schedule",
  "showInSidebar": true,
  "needsBackend": true,
  "hasSettings": true,
  "settingsFields": [
    {
      "key": "foodBlockId",
      "label": "ID столовой на сайте",
      "type": "text",
      "placeholder": "12345",
      "required": true
    },
    {
      "key": "autoDownload",
      "label": "Автоскачивание при отсутствии файла",
      "type": "checkbox",
      "default": true
    },
    {
      "key": "refreshIntervalMinutes",
      "label": "Интервал проверки (минут)",
      "type": "number",
      "default": 60,
      "min": 5,
      "max": 1440
    }
  ]
}
```

### Поля манифеста

| Поле               | Тип     | Описание                                                |
|--------------------|---------|---------------------------------------------------------|
| `id`               | string  | Уникальный идентификатор (используется в путях и JS).   |
| `name`             | string  | Человекочитаемое имя для сайдбара и админки.            |
| `icon`             | string  | Emoji-иконка.                                           |
| `version`          | string  | Семантическая версия (для отображения в админке).       |
| `author`           | string  | Автор расширения.                                       |
| `description`      | string  | Краткое описание (1–2 предложения).                     |
| `order`            | int     | Порядок внутри позиции (меньше = раньше).               |
| `defaultPosition`  | string  | `start` / `after-schedule` / `after-news` / `after-calendar` / `end`. |
| `showInSidebar`    | bool    | Показывать ли кнопку в сайдбаре киоска.                 |
| `needsBackend`     | bool    | Требуется ли C#-бэкенд (для документов).                |
| `hasSettings`      | bool    | Есть ли настраиваемые поля.                             |
| `settingsFields`   | array   | Описание полей настроек для админки.                    |

### Типы полей настроек

- `text` — однострочный текст.
- `number` — число (с опц. `min`, `max`).
- `checkbox` — галочка (`default: true/false`).
- `textarea` — многострочный текст.
- `select` — выпадающий список (с `options: [{value, label}]`).

Доп. поля: `placeholder`, `required`, `help` (подсказка под полем).

## Состояние расширений

Хранится в `data/extensions-state.json`:

```json
{
  "canteen": {
    "enabled": true,
    "position": "after-schedule",
    "settings": {
      "foodBlockId": "12345",
      "autoDownload": true,
      "refreshIntervalMinutes": 60
    }
  },
  "example-feed": {
    "enabled": false,
    "position": "end",
    "settings": {}
  }
}
```

- `enabled` — включено/выключено (выключенные не появляются в сайдбаре киоска).
- `position` — переопределённое положение в сайдбаре (если не задано — `defaultPosition`).
- `settings` — значения полей из `settingsFields`.

## Установка расширения

### Из админки

В разделе «Расширения» введите URL:
- `https://github.com/user/repo` — скачается архив main (или master) ветки.
- `https://example.ru/my-extension.zip` — прямой .zip-архив.

Архив должен содержать `plugin.json` (в корне или в подпапке). После распаковки
расширение появляется в `plugins/<id>/` и в списке админки. Для активации
нужно перезапустить киоск.

### Вручную

Скопируйте папку расширения в `plugins/<id>/`. При следующем запуске киоска
оно автоматически появится.

## Пример расширения: Столовая

Расширение `canteen` реализует все 3 механизма:

1. **Киоск** (`view.js`) — вкладка с датой и таблицей меню. Читает xlsx
   через команду `canteen.menu`.
2. **Админка** (`settingsFields`) — ID столовой, URL шаблона, имя файла шаблона,
   авто-скачивание, интервал обновления.
3. **Логика** (встроена в `WebMessageBridge`) — если файла `yyyy-mm-dd-sm.xlsx`
   нет в `data/CanteenMenu/<id>/`, пытается скачать с сайта по URL-шаблону.

### Пример настройки для foodmonitoring.ru

- **ID столовой**: `15159` (видно в URL `https://foodmonitoring.ru/15159/food`)
- **URL-шаблон**: `https://foodmonitoring.ru/{id}/food/{filename}`
- **Шаблон имени файла**: `{yyyy-mm-dd}-sm.xlsx`

Подстановки в URL: `{id}`, `{filename}`, `{yyyy-mm-dd}`, `{yyyy}`, `{mm}`, `{dd}`.
Подстановки в имени файла: `{yyyy-mm-dd}`, `{yyyy}`, `{mm}`, `{dd}`.

## Поля `showInMore` и `blockDuringLesson`

- `showInMore: true` — расширение скрывается из основного сайдбара и становится
  доступно через кнопку «✨ Дополнительно» (открывает модальную панель с сеткой
  расширений). Удобно для развлечений и редко используемых функций.
- `blockDuringLesson: true` — расширение блокируется во время активного урока
  (по расписанию звонков). При попытке открыть — показывается экран
  «Доступно только на перемене» с кнопкой возврата к расписанию.

Оба поля можно задать в `plugin.json` (значение по умолчанию) или
переопределить через админку (сохраняется в `extensions-state.json`).

## Безопасность

- Расширения выполняются в том же процессе, что и киоск. Не подключайте
  расширения из недоверенных источников.
- JS-расширения грузятся в тот же WebView2 — у них есть доступ к `window.kiosk`,
  но не к файловой системе напрямую.
- C#-плагины имеют полный доступ — они должны проходить ревью.
- Внешние HTTP-запросы должны идти через `PluginContext.HttpClient`
  с настроенным таймаутом.
