# InfoKioskApp v2.0.0

Интерактивный школьный инфокиоск на WPF с удалённым управлением, модерацией новостей и поддержкой мультимедиа.

---

## Что нового в 2.0.0

- Единый обновлённый Admin UI (логичная структура вкладок и настроек).
- Remote-панель для админа + отдельная страница редактора новостей.
- Модерация новостей: публикация/отклонение с причиной.
- Поддержка медиа в новостях:
  - фото (несколько файлов),
  - видеофайл,
  - видео по ссылке.
- Публикация и просмотр новостей прямо в приложении.
- Настройки тем, шрифтов, бегущей строки и idle-экрана через config/remote.
- Улучшения по удалённому доступу и управлению контентом (медиа, документы, расписания, календарь).

---

## Основные возможности

- **Расписание** (основное, изменённое, дополнительные файлы).
- **Столовая** (загрузка меню по `FoodBlockId`, кэширование).
- **Медиа/Документы** (удалённая загрузка и просмотр).
- **Календарь** (праздники, каникулы, выходные, свои события).
- **Погода** (текущие данные и отображение в шапке).
- **Новости**:
  - редакторы создают новости,
  - админ модерирует,
  - опубликованные новости отображаются в приложении.
- **Remote server** для администрирования по сети.

---

## Архитектура модерации новостей

### Роли
- **Админ**: создаёт редакторов, модерирует новости, управляет настройками.
- **Редактор**: создаёт новости и отправляет их на модерацию.

### Поток
1. Редактор входит в `remote/editor.html`.
2. Создаёт новость (текст + фото + видео/ссылка).
3. Новость попадает в список pending.
4. Админ в `remote/index.html`:
   - просматривает превью,
   - публикует или отклоняет (с причиной).
5. Опубликованная новость появляется во вкладке «Новости» в приложении.

---

## Структура данных (важное)

- Конфиг: `data/config.json`
- Новости:
  - `data/news/pending.json`
  - `data/news/published.json`
  - `data/news/rejected.json`
  - `data/news/editors.json`
  - медиа: `data/news/media/`

---

## Быстрый старт

1. Запустите приложение `InfoKioskApp`.
2. Откройте админ-меню (через PIN).
3. Настройте пути/параметры интерфейса/remote.
4. Включите remote-server и откройте `http://<ip>:<port>/`.
5. Для редакторов используйте `http://<ip>:<port>/editor.html`.
